# Pokémon Vault

Your all-in-one hub for the Pokémon universe — browse the Pokédex, dive into TCG sets, and search every card in one place.

Built with [Nuxt](https://nuxt.com), [Nuxt UI](https://ui.nuxt.com), [PokéAPI](https://pokeapi.co) (via [pokenode-ts](https://www.npmjs.com/package/pokenode-ts)) and [TCGdex](https://www.tcgdex.dev) (via [@tcgdex/sdk](https://www.npmjs.com/package/@tcgdex/sdk)).

## Features

- **Pokémon** — full Pokédex with sprites, types, forms, varieties and evolution chains
- **TCG sets** — every trading card game expansion, from the very first release to the latest
- **TCG cards** — search and explore every Pokémon card, filtering by name
